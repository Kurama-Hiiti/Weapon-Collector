## 概要
敵と戦い武器を集めパワーアップしていき攻略を目指すシンプルな2Dローグライクゲームです。

**ジャンル:** 2Dローグライク
*   **プレイ人数:** 1人
*   **プレイ時間:** 1時間程度
*   **ターゲット層:** ローグライクゲームが好きな方

## 特徴・アピールポイント
*   ポイント1：シンプルな操作性
*   ポイント2：複数のアイテムの実装
*   ポイント3：プレイヤーのスキル実装
*   ポイント4：バフデバフ効果やプレイヤーのステータス変動の実装
*   ポイント5：プレイヤーのアップグレード要素実装

## 遊び方（操作方法）
### 操作方法
*   **攻撃、スキル使用:** マウス操作

### ルール
1. ルール：手に入る武器を利用し敵を倒して既定のWave数クリアする

## 導入手順・起動方法
1. 本リポジトリの [Releases](https://github.com/Kurama-Hiiti/Weapon-Collector/releases) からWeapon.Collector.zipファイルをダウンロードします。
2. ダウンロードしたファイルを解凍します。
3. `Weapon Collector.exe` を実行するとゲームが始まります。

**[UnityRoom](https://unityroom.com/games/weaponcollector)にもアップロードしているのでそちらからもプレイできます。**
